# Interview

这次访谈是为了让你的智能体知道该按什么深度、用哪种方式带你练习 Codex。四个
问题都围绕本课内容，回答越具体，后面的练习就越贴合你。

## 先确认你的起点

请用一两句话告诉我：你平时用终端和 Git 的频率如何，之前有没有用过 AI 编码
智能体或类似的工具？这是自由文本，可以直接描述，也可以挑一个最贴近的选项。

## 想要的深度

练习时你希望讲到多深？可以选一个：只讲思路和关键操作、带着关键代码讲，还是
每一步都动手写出全部代码。

## 最想拿 Codex 做哪类事

这门课结束时，你最想拿 Codex 完成哪一类任务？可以选一个：改一个现有的项目、
从零做一个小工具，或者先把基本功练扎实。也可以直接说你的真实想法。

## 练习时的干预方式

练习中，你希望 Codex 直接动手改，还是先给出方案、等你确认后再改？可以选，也
可以描述你想要的别的方式。
